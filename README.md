Activity Booking Manager

📌 Description

Activity Booking Manager is a Java console-based application for managing activity bookings, 
calculating prices, and displaying booking summaries.
The project was developed as part of my Java programming studies at Nackademin.

⚙️ Features

-Create activity bookings.
-Calculate booking prices.
-Display booking information and summaries.
-Interact with users through a console-based menu.

🛠️ Technologies

Java:
Object-Oriented Programming (OOP)
Java Collections
Scanner for user input

🎯 Learning Objectives

This project helped me practice object-oriented programming,
working with classes and methods, managing user input, 
and organizing code into different responsibilities.

▶️ How to Run

Clone or download the repository.
Open the project in IntelliJ IDEA.
Run the Main class.
